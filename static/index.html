PDF 标签处理工具

上传 PDF 或 ZIP 后处理标签。可按 SellerSKU 分组输出，也可以按原文件输出。

功能说明

1. 清理信息去掉目的地中 FBA: 后面的英文/中文地址或公司名，保留 FBA/FBA:、仓库代码和周围版式。
2. 尺寸裁剪裁剪尺寸可选择 10×8、10×10、10×15cm。
3. Made In China可自行选择是否在每页底部添加 Made In China。
4. 合并规则同 SellerSKU 多个货件可选择合并生成同一个 PDF；不同 SellerSKU 会分开输出。
5. 文件命名按 SellerSKU 合并时，文件名格式为 SellerSKU-数量只.pdf；只有一个 SellerSKU 也使用该命名。
当前模式：已勾选“先识别分组”，处理时会按 SellerSKU 分开输出；只有 SellerSKU 完全一致才会合并。
